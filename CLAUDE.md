# HITCOM — Лендинг

Одностраничный лендинг для компании HITCOM (компрессоры и аспирации под ключ).

## Структура файлов

```
index.html        — актуальная версия (v4), основной файл
submit.php        — обработчик форм: запись в CSV + отправка email
data/leads.csv    — лиды (создаётся автоматически на сервере)
hitcom-v3.html    — предыдущая версия дизайна
hitcom-v1.html    — исходная версия (была index.html до редизайна)
css/style.css     — стили (используются только в v1)
js/main.js        — скрипты (используются только в v1)
```

`index.html` — полностью самодостаточный файл: весь CSS и JS встроены inline. Никаких внешних зависимостей кроме Google Fonts.

## Обработка форм (submit.php)

Принимает POST JSON, пишет лид в `data/leads.csv` и отправляет email.

- **Получатель:** `pa@atwinta.ru`
- **Отправитель:** `a42site@yandex.ru` (SMTP Яндекс, порт 465 SSL)
- Пароль приложения Яндекс прописан прямо в файле (`SMTP_PASS`)
- `mail()` **не используется** — прямой SMTP через сокет (`fsockopen ssl://smtp.yandex.ru:465`)
- Защиты: honeypot-поле `website`, rate limit 3 req/min по IP

## Технологии

- Чистый HTML/CSS/JS, без фреймворков
- Шрифты: Unbounded (заголовки), Manrope (текст), JetBrains Mono (числа/технические данные) — Google Fonts
- Акцентный цвет: коралловый `#E8524E`
- Фоновый цвет: тёплая бумага `#FAF7F0`

## Разделы лендинга (index.html)

1. **Header** — sticky, blur, телефон, кнопка «Получить КП»
2. **Hero** — заголовок, чек-листы, CTA, анимированная карточка компрессора (SVG)
3. **Stats** — 4 цифры с count-up анимацией
4. **Почему HITCOM** — 4 карточки на тёмном фоне
5. **Сегменты** — бесконечный marquee по отраслям
6. **Квиз** — 4 шага подбора + финальная форма
7. **Каталог** — карточки с 3D flip, фильтры, пагинация
8. **Отзывы и кейсы** — отзывы клиентов + кейсы
9. **Доставка и оплата** — условия двумя колонками
10. **Лид-магниты** — 3 PDF-материала
11. **FAQ** — аккордеон
12. **Финальный CTA** — форма заявки на коралловом фоне
13. **Footer** — контакты, навигация, копирайт
14. **Плавающий виджет** — телефон, Max, Telegram
15. **Попапы** — КП, консультация, фиксация цены, обратный звонок, материалы
